# Rohit Negi DSA Sheet Solutions

A structured collection of C++ solutions for problems from the Rohit Negi DSA Sheet. The repository is organized by topic for easy browsing.

## Repository Structure

```text
solutions/
├── 01. Array/
├── 02. String/
├── 03. Searching-and-Sorting/
└── 04. Linked-List/
```

## Solution Format

Solutions generally include:

- The problem statement and examples in comments
- Expected time and auxiliary-space complexity
- A `Solution` class containing the implementation

Most files are written in the format used by online judges. Depending on the platform, you may need to add headers, a `main()` function, input handling, or platform-specific data-structure definitions before compiling locally.

## How to Use This Repository

1. Open the topic directory for the concept you want to study.
2. Choose a solution file.
3. Read the problem statement and complexity expectations at the top of the file.
4. Review or run the implementation using the relevant online judge or a local driver.

- C++
